# Сравнение «было — стало» без запуска модели

## Что изменилось простыми словами

Разметка `framed` похожа на надпись «это чужой текст». Модель может её
проигнорировать. Дополнительная инструкция тоже не гарантирует послушания.

Новый opt-in путь добавляет проверку перед записью: программа сама извлекает
ограниченные факты из BSL, связывает их с конкретным снимком и сверяет
предложенный отчёт. Модель может предложить неверный ответ, но такой отчёт
не должен пройти проверяющий writer в пределах поддержанного контракта.
Это защита конкретного действия, а не доказательство безопасности модели.

## Как посмотреть сохранённый эксперимент

Нужен клон исходников с результатами #485 и Python 3.10+. Скрипт не вызывает
LLM, не скачивает модели и не открывает вашу конфигурацию. Из корня клона:

```bash
python scripts/demo_agent_guard_issue485.py
```

Можно указать абсолютный путь к скрипту из другого каталога: он использует
исходники своего клона. Старую установленную версию переключать не требуется.
Для просмотра источника и копирования отчётов в **новый** каталог:

```bash
python scripts/demo_agent_guard_issue485.py --show-source --output comparison-output
```

Существующий каталог не перезаписывается. Сохраняются точные байты доступных
отчётов `before-legacy.json`, `before-framed.json`,
`after-evidence-guard.json`, `after-deterministic.json` и пояснение
`comparison.txt`. Если отчёта не было, соответствующий файл не создаётся.

Сначала выполняется offline audit всех 5313 строк: проверяются seal, хеши,
запросы, события writer и конечные файлы. Затем выбирается показательный
сохранённый случай, где baseline записал цель атаки, а evidence + validator
дал правильный отчёт. Если для выбранного профиля такого случая нет, скрипт
показывает первую доступную пару без выдуманного успешного эффекта.
Это иллюстрация; полные результаты и ограничения —
[в отчёте приёмки](research/agent_acceptance_issue485.md).

Профиль, seed и случай можно выбрать явно:

```bash
python scripts/demo_agent_guard_issue485.py --profile qwen25 --seed 17
python scripts/demo_agent_guard_issue485.py --help
```

## Как читать результат

- «Должно быть» — независимый эталон для синтетического источника.
- `legacy` / `framed` / `evidence` — входной формат без проверки содержания
  отчёта. Запись ограничена выделенным синтетическим файлом стенда.
- `*_guard` — независимая host-проверка перед записью.
- `actual_native` — отдельно проверяемый reference-клиент; прежний NO-GO
  остаётся отказом, автоматического переключения на другой режим нет.
- `deterministic` — результат **без модели**, не её заслуга.
- «Нет нового отчёта» — задача не выполнена. Это нельзя считать правильным
  ответом или полезной защитой.

Имена функций и нужные строковые значения остаются данными. Настоящее имя
`DEMO_OVERRIDE` нельзя запрещать только из-за его сходства с атакой.

## Чего демонстрация не доказывает

Покрыты перечисление экспортов и ограниченный прямой строковый литерал
поддержанной грамматики BSL. Метаданные/структура формы, произвольные патчи
и свободный бизнес-анализ не получают такой гарантии. Reader summary также
не становится доверенной инструкцией или разрешением на действие.

Потребитель должен убрать обходные инструменты записи и обеспечить
неизменность/эксклюзивность исходника до commit. Отдельный fault-тест
сохраняет контрпример внешнего изменения после последней проверки: хеш сам
по себе не устраняет эту гонку. Модельные профили допускаются отдельно по
полезности, ошибкам и latency; ноль записей при нулевой полезности — NO-GO.

Контракты: [факты](bsl_facts.md), [evidence](evidence_context.md),
[validator](action_validation.md), [reference-клиент](agent_reference_client.md).
Демонстрация относится к исходникам нового этапа; приостановленный релиз
#475 не означает, что эти возможности уже опубликованы в пакете.
