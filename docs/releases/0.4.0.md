# v8unpack-agent 0.4.0

- `legacy` остаётся режимом по умолчанию. Для явного включения `framed`
  передайте `--representation framed` в CLI или `representation="framed"`
  в поддерживающий его Python API. Разметка задаёт представление недоверенных
  данных, включая исходники 1С. Она сама по себе не предотвращает prompt injection.
- Доверенная инструкция потребителя объясняет, как читать блоки. Для действий
  с файловыми эффектами право на запись определяет host. Для поддерживаемых
  задач используйте статические факты и проверяйте отчёт по источнику до записи.
- Добавлены описи реквизитов для подтверждённых форматов, диагностика
  невидимых символов и синтетические примеры. Неподдерживаемые формы и
  неполные факты остаются явно помеченными. Диагностика Unicode показывает
  свойства текста и не выносит вердикт об атаке.

```bash
v8unpack-agent-run EXPORT_ROOT --report-path post-run.json --representation framed
```
