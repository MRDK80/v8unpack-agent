# Прямые динамические операции формы

Opt-in library API `v8unpack_agent.dynamic_forms_detector` (#214), основанный на
[MVP #212](research/dynamic_forms_issue212.md) и [модели #213](dynamic_forms.md).
Детектор не выполняет BSL, не восстанавливает runtime-дерево и не меняет
существующие парсеры форм, FormContext или runner.

## Граница API

```python
from v8unpack_agent.dynamic_forms_detector import detect_form_operations

index = detect_form_operations(
    'Procedure Build() Items.Add("Demo", Type("FormField")); EndProcedure',
    'CommonForm/Demo/Module.bsl',
    declared_elements=(),
    declared_commands=(),
    declared_attributes=(),
)
assert index.operations[0].target.creation_operation_id
```

Caller заранее определяет, что источник является модулем формы. Функция не
применяется к произвольному общему модулю только из-за слова `Элементы`.
`text` — текстовый снимок, путь — относительный POSIX-путь с общей проверкой
POSIX/Windows. Хеш источника относится к UTF-8 тексту без нормализации строк;
позиции — символьные offsets и включительные номера строк модели #213.
Файлы не читаются и не записываются самим детектором.

`declared_elements`, `declared_commands` и `declared_attributes` — tuple подтверждённых caller имён
соответствующего вида. Отсутствие имени в переданной описи не доказывает его
отсутствие в форме. Простое совпадение с любым полем `name` в JSON не является
такой описью. Имена сравниваются через casefold. Качество и происхождение
декларативной описи остаются ответственностью producer. Статические реквизиты
учитываются при проверке затенения контекста формы. На корневой форме
без доказательства расширения точными свойствами считаются Title и ReadOnly;
прочие совпадения с whitelist элементов сохраняются unresolved.

Возвращается `DynamicOperationIndex`. Декларативные записи в него не копируются.
Пустой индекс означает отсутствие распознанных операций в поддержанной грамматике,
а не доказанное отсутствие всех динамических изменений формы.

## Поддержанные конструкции

- Добавить/Вставить/Удалить/Переместить элементы; Add/Insert/Delete/Move.
- ИзменитьРеквизиты / ChangeAttributes.
- Добавить/Удалить команды; Add/Delete.
- Прямые присваивания 13 свойств MVP, в RU/EN написании и любом регистре.

Прямые коллекции: `Элементы` / `Items`, `Команды` / `Commands`, в том числе через
`ЭтаФорма` / `ThisForm` / `ЭтотОбъект` / `ThisObject`. Параметры, переменные модуля,
локальные объявления и возможные bare-присваивания проверяются до доказательства
получателя. Неоднозначное bare-сравнение с тем же именем может консервативно
снять доказательство; присваивания после Try/Except, меток или директив нельзя
пропускать из-за отсутствия обычной границы оператора.
Похожий суффикс `Demo.Items.Add(...)` не становится коллекцией формы.
Локальная процедура с именем ChangeAttributes затеняет неявный платформенный вызов.

Создание с доказанным получателем получает exact-ссылку на собственный ID даже
при partial-имени. Присваивание `Items.Demo.Visible = True` подтверждается только
при переданном declared-имени Demo. Прямое свойство `ThisObject.Title` относится
к форме при незатенённом получателе. Алиасы результатов создания, поиск по имени,
индексация коллекции и связи между операциями относятся к #215. Алиасный setter
может сохраняться как unresolved; вызов через произвольный алиас коллекции на
этом этапе не распознаётся. Неявное присваивание свойства формы без получателя
(например, `Заголовок = "Demo"`) также пропускается: локальная переменная не
должна автоматически становиться свойством формы.

Литеральные строки, целые, Boolean и null-подобные значения exact. Undefined и
Null сохраняют исходное выражение, но используют один JSON scalar null.
Десятичное число exact только при представимости без округления в float;
иначе оно остаётся partial. Целые длиннее 1024 цифр остаются partial
до вызова int(), независимо от системного лимита версии Python. Незатенённый `Тип("ПолеФормы")` / `Type("FormField")`
сохраняет символическое имя типа, а не runtime-объект и не доказательство
успешного выполнения вызова. Иные выражения не вычисляются. Родитель/позиция
могут быть exact declared-ссылками; пропущенный аргумент обозначается явно.

## Условия и позиции

Поддержаны If/ElseIf/Else, циклы и условные директивы препроцессора. Известное
исходное выражение не означает известную истинность: runtime truth всегда unknown.
ElseIf хранится как отрицательная ветвь предыдущих guard и положительная ветвь
нового guard, без вычисления или выдуманного отрицания выражения.
Вызов в заголовке If выполняется при вычислении условия и не получает контекст
ветви Then. Аналогично заголовок цикла не является телом цикла.
Try/Except помечают последующий контекст процедуры как неполный.
Goto и Execute дают явный отказ всего модуля `dynamic_control_flow`, поскольку
могут повторно посетить уже разобранные позиции. Активный контекст ветвей,
включая накопленные отрицания ElseIf, ограничен 64 ссылками.
Детектор не доказывает достижимость, число итераций или отсутствие исключений.

Диапазон вызова начинается с получателя и заканчивается закрывающей скобкой;
setter — с получателя до конца значения, без точки с запятой. Комментарии и
строки атомарны для лексера, многострочность не меняет координаты. Единица
подсчёта — синтаксическое место операции, не число runtime-вызовов.

## Отказы и бюджеты

`DynamicAnalysisError.status` — unsupported или incomplete; `reason` — техническая
причина без исходного фрагмента. Отказ отличен от успешного пустого индекса.
Некорректный аргумент Python API или относительный путь даёт TypeError/ValueError.
Лексические примитивы `bsl_facts` используются внутренним адаптером; публичный
строгий контракт bsl_facts не ослабляется. Условные директивы маскируются с
сохранением позиций; обе ветви остаются данными, платформа не эмулируется.

Неизвестная директива, некорректная строка/дата, незавершённый блок, неподдержанный
код инициализации модуля или неоднозначные условные объявления процедур приводят
к отказу модуля. Неподдержанная арность известного вызова коллекции сохраняется
как unresolved с причиной unsupported_syntax и provenance unsupported_call_arity;
соседние доказанные операции не стираются. Такая запись не доказывает создание.

По умолчанию `max_chars=2_000_000`; caller может задать положительное целое.
Внутренние пределы: 64 уровня вложенности, 10 000 операций и 10 000 условий.
Превышение даёт явный отказ вместо частичного полного индекса.
Детектор не является полным валидатором грамматики или компилятором BSL.

## Данные и проверка

JSON по умолчанию скрывает выражения по контракту модели, но сохраняет имена,
литералы и относительные пути. Это недоверенные данные и не обезличенный отчёт.
Передача внешней модели требует framed-контракта и решения host; этот модуль
не запускает модели. Замеры публикуются только агрегатами, без реальных имён,
путей и BSL. Корпус #212 используется как регрессионный, не holdout.

Синтетические проверки находятся в `tests/test_dynamic_detector_*.py`.
Связывание — #215; решение о приросте data flow — по замерам #216;
интеграция контекста и отчёта — #217.
