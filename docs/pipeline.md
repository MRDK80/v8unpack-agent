# Контракт пайплайна

Документ фиксирует фактический входной контракт библиотечного пайплайна,
ответственность распаковщика и границы пакета. Описаны только существующие
публичные сущности.

## Чего в пакете нет

- Функции `index_cf()` не существует. Единой точки входа, которая сама
  выполняет опись, распаковку, индексацию и проверку дрейфа, пакет не
  предоставляет.
- Функции `rag.rebuild()` и подсистемы RAG в пакете нет. Внешняя индексация
  находится вне scope `v8unpack-agent`.
- Production-адаптера одиночного `Form.bin` пакет не содержит: реализацию
  распаковщика инъектирует вызывающая сторона.

## Два уровня входа

Уровни не смешиваются.

1. **Подготовка дерева.** Контейнер конфигурации (`.cf` и родственные)
   раскладывает в дерево файлов upstream-инструмент `v8unpack`: целый
   контейнер — его штатная точка входа. Поштучный `Form.bin` документированным
   upstream-входом не является.
2. **Библиотечная обработка.** `v8unpack-agent` получает уже подготовленный
   `dump_root` — корень файлового дерева выгрузки, а не путь к контейнеру.
   Автоматической распаковки контейнера пакет не выполняет.

## Фактические сигнатуры

```python
discover_form_sources(dump_root: Path) -> list[FormBinSource]

unpack_all_forms(
    dump_root: Path,
    unpacked_root: Path,
    unpacker: FormUnpacker,
    *,
    form_ids: Iterable[str] | None = None,
    form_names: Iterable[str] | None = None,
) -> list[FormArtifact]

unpack_erf(
    erf_path: Path,
    unpacked_root: Path,
    unpacker: ErfUnpacker,
) -> FormArtifact

update_forms_index(
    dump_root: Path,
    unpacked_root: Path,
    artifacts: Iterable[FormArtifact],
    *,
    index: FormsIndex | None = None,
) -> FormsIndex
```

Отбор по `form_ids` каноничен. Параметр `form_names` оставлен для
совместимости и не является надёжной идентичностью: одноимённые формы разных
владельцев различаются только по `form_id`.

`update_forms_index()` берёт источник из самого артефакта, поэтому повторное
обнаружение форм не выполняется и потеря записи по имени невозможна (#226).
Ключ записи — `form_id`. В индекс пишутся только относительные POSIX-пути,
поэтому файл остаётся обезличенным и одинаковым на POSIX и NT.

## Контракт FormUnpacker

```python
FormUnpacker = Callable[[FormBinSource, Path], FormArtifact]
```

Это callable-псевдоним типа, а не класс и не `Protocol`.

- Первый аргумент — канонический источник формы: `form_id`, имя формы, путь к
  `Form.bin` и метаданные владельца.
- Второй аргумент — корень текстового слоя (`unpacked_root`).
- Каталог результата определяется безопасным `form_id`, а не именем формы;
  разрешение пути защищено от выхода за корень.
- Результат — `FormArtifact` с той же идентичностью и источником.
- Реализация обязана явно сообщить неполноту через `extraction_ok=False` и
  непустой `extraction_warnings`; скрывать частичный результат запрещено.
- Конкретной реализацией владеет вызывающая сторона.

## Legacy-контракт

```python
LegacyFormUnpacker = Callable[[Path, Path, str], FormArtifact]
```

Подключается только через `adapt_legacy_unpacker()`. Адаптер выдаёт
`DeprecationWarning`. Новые интеграции пишутся сразу под `FormBinSource`.
Legacy-функция `discover_form_bins()` возвращает карту `dict[str, Path]` по
имени формы и остаётся совместимым shim, а не каноническим API обнаружения:
неоднозначные имена не должны использоваться как идентичность. Срок удаления
legacy-слоя не объявлен.

## Полный и частичный результат

`FormArtifact` — frozen dataclass со следующими полями:

| Поле | Смысл |
|---|---|
| `name` | имя формы, как в выгрузке |
| `paths` | пути текстов формы: `object_module`, `ext_module`, `metadata` |
| `extraction_ok` | `True` — распаковка полная, `False` — частичная |
| `extraction_warnings` | диагностика неполноты, при `extraction_ok=False` непуста |
| `skd_extracted` | только для `.erf`: запросы СКД извлечены |
| `elem_index_ok` | структура формы извлечена из `elem.json`, best-effort |
| `form_id` | канонический идентификатор формы (#226) |
| `source` | исходный `FormBinSource` или `None` |

Правила чтения результата:

- `extraction_ok=False` — не отказ пайплайна, а сигнал «видна только часть,
  не делай выводов о полноте»;
- инвариант конструктора запрещает `extraction_ok=False` без предупреждений,
  поэтому тихая частичная распаковка невозможна;
- `elem_index_ok` и `skd_extracted` — best-effort и на `extraction_ok` не
  влияют: агент может видеть BSL-модуль без структуры формы или без СКД;
- полей вида `status` или `reason` в артефакте нет;
- канонический пайплайн всегда заполняет `form_id` и `source`, хотя сам
  dataclass допускает пустые значения для совместимости.

## Примеры и тестовые распаковщики

Распаковщик из `examples/basic_usage.py` и распаковщики в тестах —

## Граница пакета

Пакет заканчивается на `FormArtifact` и `FormsIndex`. Результаты могут быть
переданы внешнему индексатору или RAG-системе, но сама индексация находится
вне scope `v8unpack-agent`, и заглушки `rag` в пакете нет.
