# Проверяемые BSL-факты

Opt-in library API `v8unpack_agent.bsl_facts`, схема `bsl_facts/1`,
`EXTRACTOR_VERSION = "bsl-facts/1.0"`. Основание —
[ADR #480](research/agent_defense_adr_issue480.md).
CLI, canonical source, embeddings и существующие transport-схемы не меняются.

## Выбор источника

```python
from pathlib import Path
from v8unpack_agent.bsl_facts import analyze_indexed_module

# index и module_id выбирает доверенный host из своего ModuleIndex.
facts = analyze_indexed_module(Path("export"), index, module_id)
if facts.status == "complete":
    names = facts.exported_function_names
else:
    # None означает неизвестное, а не отсутствие экспортов.
    reason = facts.reason
payload = facts.to_dict()
```

`analyze_indexed_module(root, index, module_id, *, max_chars=2_000_000)`
читает только путь записи существующего `ModuleIndex`, требует SHA-256,
проверяет размер при его наличии и отклоняет symlink-компоненты.
Идентификатор от модели сам по себе не разрешает чтение: host выбирает
допустимые root, index и scope. Файлы и индекс не изменяются.

`analyze_module(entry, bsl_text, *, bsl_bytes=None, max_chars=2_000_000)` —
чистый анализ уже выбранного текста. При переданных байтах проверяются хеш
и размер записи, соответствие текста байтам. Без байтов снимок помечен
`text_only` и не доказывает соответствие файлу индекса.
Бюджет — число символов; `-1` явно снимает ограничение. Чтение из файла
дополнительно ограничено числом UTF-8 байтов. Превышение даёт `incomplete`.

## Результат и evidence

Все публичные структуры — frozen dataclasses:

- `ModuleFacts`: `module_id`, `status`, `reason`, `source`, `declarations`,
  `extractor_version`. `exported_function_names` — tuple при `complete`,
  включая подтверждённый пустой tuple; иначе `None`.
- `DeclarationFact`: `fact_id`, `kind` (`function`/`procedure`), исходное
  `name`, `exported`, `asynchronous`, `parameters`, `start_line`,
  `header_end_line`, `end_line`, `returned_string`.
- `LiteralFact`: собственные `status`, `reason`, `value`, `fact_id`,
  `start_line`, `end_line`. `unsupported` не делает неизвестным подтверждённое
  объявление, но запрещает считать значение вычисленным.
- `SourceSnapshot`: `module_id`, относительный путь, неизменяемые `text` и
  необязательные `raw`, хеши текста/байтов, `normalization`, `source_id`.
  `to_dict()` не включает полный текст и байты; repr тоже их скрывает.

Нумерация строк начинается с 1, границы включительны. Идентификаторы фактов
включают версию extractor, снимок и диапазон; при изменении комментария
семантический набор объявлений сохраняется, но evidence привязывается к
новому источнику. Хеш — идентичность/целостность, не полномочия автора.

Статусы: `complete` — полный синтаксический список объявлений в поддержанном
подмножестве; `unsupported` — грамматика вне покрытия; `incomplete` —
обрыв/неоднозначность/бюджет/устаревший индекс; `unavailable` — источник
недоступен, не индексирован, без хеша или не декодируется. При любом статусе
кроме `complete` наружу не выдаётся правдоподобный частичный список.
Причина — стабильный технический код без исходного текста и абсолютного пути.

## Покрытие и ограничения

| Конструкция | Поведение |
|---|---|
| RU/EN, смешанный регистр ключевых слов | Поддержаны, имена сохраняются точно |
| Функции/процедуры, Export/Экспорт, Async/Асинх | Поддержаны, включая многострочные заголовки |
| Параметры, Val/Знач | Имена в исходном порядке; дубликаты без учёта регистра отклоняются |
| Defaults | Строки (включая соседние), числа со знаком, даты из цифр, bool/null/undefined; вызовы/выражения не вычисляются |
| Комментарии `//`, строки с удвоенными кавычками | Не создают объявлений, не интерпретируются как инструкции |
| Многострочная строка | Продолжение с `|`; объявления внутри не учитываются |
| BOM/CRLF/CR/LF | Поддержаны, исходные байты сохраняются; нормализация явно указана |
| Unicode | Буквы/подчёркивание и ASCII-цифры в именах; без переименования/NFKC. Cf в комментариях/строках сохраняется, вне их — unsupported |
| Дубликаты объявлений | unsupported при casefold-совпадении; визуальные confusables не отождествляются |
| `#Region`/`#Область` | Только сбалансированные; незакрытая область — incomplete |
| Клиент/сервер compiler annotations | Базовые `AtClient`, `AtServer`, `AtServerNoContext`, комбинированные и RU-аналоги |
| Условный preprocessor, расширения Before/After и неизвестные annotations | unsupported; активная ветвь/runtime-доступность не угадывается |
| Переменные модуля | Простые объявления до функций; функции после исполняемого кода отклоняются |
| Прямой возвращаемый литерал | Только тело функции `Return "..."` с необязательным `;`, комментариями и одной строкой литерала |
| Конкатенация, вычисления, ветвления, многострочный возвращаемый литерал | Литерал unsupported; объявления могут оставаться complete |

Это отдельный ограниченный lexer/scanner, без использования старых regex
`search_fragments._masked/_regions`. Это не AST, компилятор и не проверка
корректности произвольного тела BSL. `complete` не доказывает успешную
компиляцию и не означает, что экспорт доступен во всех runtime-контекстах.
Поддержанный литерал может содержать инструкции и управляющие символы:
он остаётся данными, а не разрешением host выполнить действие.
Реально объявленное имя `DEMO_OVERRIDE` допустимо.

Host должен заново проверить snapshot/scope/полноту перед эффектом.
Чтение с проверкой symlink не является OS sandbox против другого процесса
с теми же правами; оно не устраняет TOCTOU само по себе. Эти структуры не
дают модели право писать файл или подтверждать собственный хеш.

Тесты: `tests/test_bsl_facts_issue481.py` — независимые ожидаемые результаты,
грамматика, старый development-корпус, настоящие изменения объявлений,
необходимые литералы, несовпадение снимков и stale index. Held-out #485
для разработки этого анализатора не запускается.
