# Итоговая проверка динамических форм (#218)

Проверен применимый MVP #211: модель #213, локальный detector #214,
linker #215 и opt-in интеграция #217. B0 #216 отложен по quality gate;
расширенный data flow не объявляется реализованным. Результат описывает
операции в исходнике, а не гарантированное runtime-дерево формы.
[Матрица классов и остатка](../dynamic_forms_coverage.md).

## Протокол и детерминизм

Повторно использованы четыре frozen corpus #212, реальные записи сканера
и тот же закрытый scope. Корневые конфигурации различны; байтовые повторы
и общие библиотеки не считаются независимыми наблюдениями качества.
Первичный знаменатель — 7012 managed-модулей (812 / 245 / 52 / 5903).

Выполнено 16 fresh-process проходов: default-off и opt-in по два запуска
на каждой C1–C4. Все восемь пар имеют одинаковые хеши результата,
счётчики и причины отказов. Исходники пакета перед/после проходов совпали:
`7a2c39e9cb4b840712365d1cb2937c0f2dd4630c07b24424a3f1dad9332941a7`.
Core detector/linker по-прежнему имеет SHA #215
`3dd78a0a0b4bc758f036022b304690aa7e06cca2de2ca22196fa8a3c468ee48c`.
Полные манифесты 141 912 файлов повторно проверены после серии, изменений нет.

Диагностические попытки 1–3 исключены целиком: граница discovery/wall,
нормализация CRLF и квадратичный formatter соответственно. Окончательная
серия — revision 4, после исправлений. Для 12 завершённых C1–C3 результатов
до/после оптимизации formatter дополнительно совпали хеши данных и счётчики;
их прежние performance-числа не смешиваются с окончательной серией.

## Качество

Основной regression gold: 31 полностью прочитанный модуль, 420 операций,
из них 364 в закрытом MVP. Единица — вид операции и строка метода/знака
присваивания. Изменение resolution само по себе не добавляет TP: требуется совпадение
с вручную подтверждённым сайтом; точность значения и ссылки оценивается
отдельно. Оценка через настоящий FormContext:

| Корпус | Gold MVP | TP | FP | FN |
|---|---:|---:|---:|---:|
| C1 | 82 | 2 | 0 | 80 |
| C2 | 30 | 1 | 0 | 29 |
| C3 | 187 | 73 | 0 | 114 |
| C4 | 65 | 6 | 0 | 59 |
| Всего | 364 | 82 | 0 | 282 |

Результат совпал с #215: на этом наборе precision 100%, recall 22,53%.
Это оценка присутствия подтверждённых сайтов, не независимая экспертиза
каждой связи всего корпуса и не population guarantee. Отдельный raw baseline
#214 — 250 TP / 0 FP / 114 FN. 168 истинных сайтов, пониженных linker до
unresolved, остаются FN; их не переименовывали в negative/out of scope.

Дополнительные 12 полностью прочитанных модулей выбраны до просмотра A/B
#216 и исключают прежние модули/совпадающие байтовые SHA. В них 28 операций,
18 MVP: 4 TP / 0 FP / 14 FN, без изменения после интеграции. Один annotator,
без независимого экспертного ревью. Частоты исследования #212 описывают
scope (62071/79770 = 77,81%), а не достигнутое покрытие реализации.
Количество записей полного корпуса не используется как TP/recall.

## Стоимость относительно default-off

Linux, Python 3.12.3. Подготовленные записи сканера загружаются до wall;
первоначальный discovery измерен отдельно. Builder включает чтение и
построение контекста. Wall включает также проверку файлов, каноническую
сериализацию для hash и обе проекции с лимитом 8000. RSS — весь процесс,
включая импорт и подготовленные входы. Замеры описательные на одном host,
без статистической гарантии времени в других окружениях.

| Корпус | Builder off, с (1 / 2) | Builder on, с (1 / 2) | Wall off, с (1 / 2) | Wall on, с (1 / 2) | RSS off, МиБ (1 / 2) | RSS on, МиБ (1 / 2) |
|---|---:|---:|---:|---:|---:|---:|
| C1 | 6.654 / 6.472 | 38.383 / 38.225 | 11.605 / 11.335 | 44.286 / 44.078 | 57.7 / 57.9 | 104.2 / 105.2 |
| C2 | 1.352 / 1.335 | 10.444 / 10.521 | 3.095 / 3.067 | 12.467 / 12.586 | 48.1 / 48.2 | 60.7 / 60.5 |
| C3 | 0.232 / 0.245 | 1.730 / 1.739 | 0.465 / 0.487 | 2.030 / 2.039 | 27.0 / 27.5 | 36.5 / 36.9 |
| C4 | 49.453 / 49.493 | 374.426 / 386.918 | 90.584 / 90.836 | 425.520 / 439.085 | 184.4 / 184.4 | 215.5 / 214.0 |

Атомарная секция динамики может опуститься вместе с последующим BSL,
поэтому объём/стоимость проекции отличается между режимами; builder
показан отдельно. Dynamic default-off не вызывает analyzer и сохраняет
прежние metadata/фрагменты/ключи report. 124 фрагмента 31 реального модуля
(`legacy`/`framed`, лимиты −1/8000) совпали побайтово с замороженным
`form_context` v0.4.0 из `85d0d37ae5740601bb45f31f940ad9de486121d3`.

Исправление `framed` при символьном лимите сохраняет байты и убывающий
порядок токенных проверок. Синтетические 2000 строк / лимит 1000:
1954 → 14 кодирований, 1,880 → 0,006 с, одинаковый выходной SHA.
Полный блок рассматривается отдельно от усечённых из-за поля `omitted`.
Произвольный token-only счётчик без символьного ограничения может требовать
перебора. Инженерный лимит 2× #216 относился к B0 против анализирующего A,
а не к включённому контексту против baseline без динамического анализа.

## Runner и post-run report

Отдельно настоящий runner C3 запущен default-off/on по два раза на всех
76 обнаруженных формах, без общих модулей, СКД и reference-resolution.
Это другой знаменатель, чем 52 managed-модуля основной таблицы.
После исключения временных меток SHA report совпал в каждой паре.

Default-off: 58 complete / 18 partial. Opt-in: 51 complete / 25 partial;
динамический блок: 76 форм = 51 complete + 7 unsupported + 18 unavailable,
373 операции = 39 exact + 119 partial + 215 unresolved, 225 conditional,
315 кандидатов. Числа совпали с соответствующим индексом. Новая часть
report содержит только целые агрегаты, без BSL/имён/путей.

## Сквозные контракты и остаток

Тридцать новых mixed-проверок #218 покрывают восемь видов и 13 свойств
позитивными/отрицательными примерами, комментарии/строки, похожие пользовательские
процедуры, declared + exact/partial/unresolved, guard с unknown truth,
один loop-шаблон, opaque helper, конфликты и равенство builder/report counters.
Они дополняют tests #213–#217. Синтетический пример показывает эти слои
без production-данных и печатает `framed`; моделей не вызывает.

Реализован закрытый набор #212/#214/#215, включая локальные identity-copy
и закрытые root-массивы реквизитов. B0 #216 не прошёл пороги: +7 TP и 2,48%
устранённых FN при требовании ≥20 TP и ≥20%; более широкий literal/CFG/effect
flow остаётся неизмеренным. Он не объявляется реализованным или бесполезным.
Обработчики событий (737 подтверждённых мест) и другие setters (16962)
отложены за пределами принятого whitelist. Межмодульный анализ, выполнение
конфигурации, конечное runtime-дерево, embeddings и LLM-провайдеры вне scope.
Неполные declarations отдельно отслеживаются в #562.

Library/projection сохраняют имена и необходимые литералы как недоверенные
данные и не являются обезличивателем. Публичны только агрегаты и синтетика.
`framed` — контракт представления, не доказательство устойчивости модели
к injection. Запусков моделей и runtime-конфигурации не было.

[Обезличенные агрегаты](dynamic_forms_issue218_aggregates.json) фиксируют
все парные хеши, причины отказов, baseline, gold и проверки неизменности.
