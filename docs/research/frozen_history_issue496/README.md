# Неизменный исходник исторических модельных экспериментов

Добавление нового opt-in модуля изменяет glob списка текущего пакета. Старые
seals #484/#485 фиксируют первоначальный набор файлов и обязаны сохраняться.
source.zip содержит точные исходные байты объединения обоих sealed наборов
и первоначальный portable adapter #485 из принятого9e9ede9c. Все исходные
хеши проверены против прежних seals перед упаковкой, новые модули не добавлены.
manifest.json фиксирует архив/каждый файл; helper проверяет постоянный SHA256.

`python -m scripts.replay_frozen_history_issue496 484` (либо485) создаёт
временный исходный tree, копирует неизменные опубликованные результаты и
запускает старый audit в отдельном Python-процессе. Старые source/seal/request/
effect/hash checks не отключаются. Сеть, модели и git-история не нужны.
Для cross-Unicode tests переносится только объявленная диагностическая метка,
по прежнему portable adapter; payload/факты/значения не меняются.

Три исторических archive-теста явно вызывают этот helper вместо текущего
исходного tree; их assertions и frozen исходники не меняются. Остальные unit/
интеграционные тесты продолжают проверять текущий продукт. Это сохранение
исторической воспроизводимости, **не приёмка нового кандидата** старыми ответами.
Новые GO/NO-GO требуют отдельного замороженного прогона и R16.
