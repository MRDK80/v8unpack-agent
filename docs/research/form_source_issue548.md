# Источник объявлений обычных форм 0-5-1 (#548)

Проверили исходный CF выборки C через v8unpack 1.2.13. Для пилотной
записи сопоставили UUID из файла идентичности с именами членов
контейнера после распаковки и декомпрессии. Найдены член без суффикса
с заголовком объекта и член `.1`. Член `.0` отсутствует при сравнении
имён без учёта регистра. В заголовке нет другого UUID, по которому
можно было бы связать его с членом структуры.

В установленном декодере обычной формы `.0` служит источником корня,
а `.1` читается отдельно. Разобранный brace-документ `.1` целиком
совпал с единственным блоком `form` в JSON пилотной записи. Его
HTML ранее сопоставлен со справкой в отдельной выгрузке Конфигуратора.
[Код FormCore](https://github.com/saby-integration/v8unpack/blob/main/src/v8unpack/MetaDataObject/Form/FormCore.py) ·
[Сверка с Конфигуратором #541](form_help_issue541.md)

| Проверка | Пилот | Все записи |
| --- | ---: | ---: |
| UUID сопоставлен с заголовком и `.1` в исходном CF | 1 | 54 |
| Член `.0` или другой член с тем же UUID | 0 | 0 |
| Точное равенство разобранного `.1` и блока `form` | 1 | 54 |
| Результат подтверждён свежей распаковкой того же CF | 1 | 54 |
| Подтверждённые списки объявлений, включая пустые | 0 | 0 |

Число `0` в конце блока справки не имеет подтверждённой связи с числом
реквизитов. Пустой `props` относится к результату распаковки. Для
проверки имён и порядка потребуется исходный член структуры, выгрузка
Конфигуратора с объявленными реквизитами или проверенный декодер,
который связывает этот заголовок с источником объявлений и подтверждает
полноту списка. В проверенной копии CF и выгрузке Конфигуратора такой
источник не найден. Статус всех 54 записей остаётся `unsupported`.

## Повтор

1. Распакуйте выбранный CF тем же v8unpack в новый локальный каталог,
   выделив отдельный временный каталог через параметр `temp_dir`
   функции `v8unpack.v8unpack.extract`. Сохраните `decode_stage_1`.
2. Из корня checkout с установленным пакетом выполните:

   ```bash
   python scripts/audit_form_members_issue548.py EXPORT DECOMPRESSED_CONTAINER
   ```

   Второй аргумент — каталог выбранного контейнера внутри
   `decode_stage_1`. Скрипт связывает записи по UUID и выводит только
   числа. Выполните его для прежней и новой выгрузок того же CF.
3. Для A/B/C повторите [процедуру #545](form_audit_issue545.md) с теми же
   локальными пределами и отдельно сверенными четырьмя восстановленными
   парами A. Контрольное покрытие остаётся **5976 из 6030**. Выгрузки,
   UUID и содержимое членов остаются локальными.
