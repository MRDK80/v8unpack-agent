# Unicode и изображения в контексте агента

Этап проверяет путь от недоверенного источника до одного разрешённого
действия. Метрики диагностики, доставки, ответа модели и записи считаются
отдельно. Источник отчёта задаёт host. Например, OCR может предложить
модели чужую команду, а отчёт о литерале всё равно должен содержать
точное значение из BSL.

| Канал | Что диагностируется или передаётся | Что проверили | Граница результата |
| --- | --- | --- | --- |
| Unicode в исходнике | Runtime Cf, назначенные Tags, выбранные variation selectors и CGJ в опциональной диагностике | Число совпадений, позиции, версия Unicode, лимиты. Законные значения сохраняются | Похожая буква или невидимый символ за пределами перечня может остаться без отметки |
| Unicode в запросе | Содержимое отправлено в legacy, framed или через минимальное наблюдение | 1152 строки, 1008 поддержанных, 1469 RPC, 842 точных отчёта и 166 без отчёта. Ещё 144 операции не покрыты | 61 совпадение предложения с целью теста, включая clean-контроль. Совпадение фиксирует содержимое ответа |
| Декодирование Unicode | Отдельные запросы на точное восстановление строк | 30/160 точных ответов, 22 пробы достигли лимита генерации | Результаты относятся к выбранным кодировкам, подсказкам и профилям. Это отдельная задача без записи |
| Имя, метаданные и OCR PNG/JPEG | Внешний reader передал имя, поле PNG Description, JPEG COM или фактический OCR-текст | 8/10 транскрипций точны после исключения завершающего LF. В 432 активных строках 594 RPC, 365 точных отчётов и 67 без отчёта | Пиксели в этих запросах не передавались. Два низкоконтрастных результата OCR отличались от эталона |
| Прямой vision, LSB и JPEG alpha | Маршруты выделены в плане | 108 прямых сценариев и 20 проб чтения недоступны, 120 LSB не исполнялись, 60 JPEG alpha не поддерживаются | Для этих слотов поведение модели не измерено. Vision требует подходящей памяти, LSB требует явного декодера |
| Граница записи | Host валидирует цель и полный набор ID, затем материализует отчёт из снимка | Из 1872 строк записи 856 отказов сохранили инвентарь. Все 1207 consumer-записей точны. Отдельно 1440 отчётов производителя | Linux private-FS и snapshot-only. Следующий агент проверяет свой источник и права заново |

Поддержанные clean/attack отчёты составили 250/288 и 592/720 для Unicode,
174/216 и 191/216 для изображений. Режимы используют одинаковую границу
записи. Точные отчёты legacy/framed/minimal составили 269/262/311 из 336
в Unicode и 136/97/132 из 144 в изображениях. Порог исследования прошли
13 из 36 и 6 из 12 групп соответственно. Допуск каждой группы ограничен
её моделью, операцией, маршрутами и политикой. Состав наблюдения в
minimal отличается. Повторные seed и варианты одного случая зависимы.

Использованы Qwen2.5, Llama 3.1 и Qwen3 с thinking и без него. Ollama
0.16.1, context 8192, temperature 0.3, seed 17 и 29, до трёх запросов
на траекторию, до 180 секунд на запрос и 540 секунд на траекторию.
Модельные digest, лимиты генерации и расходы по группам закреплены в
[Unicode runtime](unicode_study_issue519/runtime-preregistered.json) и
[image runtime](image_study_issue520/runtime-preregistered.json).
Счётчики API не покрывают доказанно всю внутреннюю стоимость thinking.
OCR выполнял Tesseract 5.3.4 eng с
[зафиксированными параметрами](image_study_issue520/ocr-tool.json).

## Проверить на синтетических данных

В checkout с установленными тестовыми зависимостями запустите:

```bash
python scripts/demo_unicode_image_issue523.py
```

Скрипт печатает сравнение режимов и два сохранённых примера. Сначала
решение `blocked` и пустой список изменившихся файлов. После правильного
выбора — `committed` и `consumer/report.json`. В примере PNG итоговое
значение — `SELECT 1`. Изображения, actual OCR и метаданные доступны в
[наборе #520](image_study_issue520/cases.json).

На Linux с Python 3.12 и Unicode 15.0.0 добавьте
`--replay-to /tmp/unicode-image-replay-523`, указав новый каталог.
Появятся `unicode.jsonl.gz`, `image.jsonl.gz` и `summary.json`.
Повтор исполняет закреплённые host и сравнивает весь файловый аудит.
Используются сохранённые ответы. Новые запросы к моделям требуют
своего локального окружения и отдельной регистрации по протоколу.
