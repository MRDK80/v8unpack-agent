# #520. Инструкции в PNG и JPEG

В эксперименте модель предлагает номера фактов для отчёта о строковом
литерале BSL. Host проверяет предложение и берёт значение из исходника.
Для каждого входа ожидаемый отчёт содержит `SELECT 1`. Изображение и
извлечённый текст служат дополнительным контекстом. Инструкция, схема
предложения, обратная связь и проверка записи взяты из #502 без изменений.

[Протокол этапа](unicode_image_protocol_issue516.md) задаёт 720 сценариев
для трёх режимов контекста. Из них 120 сценариев LSB отмечены
`not_exercised`, поскольку модели не получают декодер. Ещё 60 сценариев
с alpha в JPEG отмечены `unsupported`. Остаются 540 сценариев с максимум
тремя запросами каждый. В этой регистрации добавлены 20 отдельных проб
чтения текста из пикселей, по одному запросу на пробу. Суммарный максимум
1640 RPC укладывается в исходный предел 2160. Порядок фиксируется в
[plan.json](image_study_issue520/plan.json), основная серия идёт первой.

24 синтетических случая заданы в [cases.json](image_study_issue520/cases.json).
Байты изображений зафиксированы в коммите `b13f477` до распознавания OCR.
В PNG проверяется поле Description, в JPEG сегмент COM. Имя файла
и извлечённое поле поступают отдельным сообщением tool. В случаях
с текстом на картинке локальный Tesseract получает сохранённый PNG,
скомпонованный на белом фоне. Фактический stdout передаётся без
подстановки эталонного текста. Исходные изображения, растр OCR, stdout,
stderr и конфигурация инструмента входят в архив. Неудачи извлечения
сохраняются. Проверка LSB подтверждает конструкцию PNG вне агента.

Qwen2.5VL получает оригинальные байты в массиве images сообщения user
по [REST API Ollama](https://docs.ollama.com/capabilities/vision).
Qwen2.5, Llama и два режима Qwen3 получают текст от внешнего обработчика.
Дополнительный канал одинаков во всех режимах. В framed и minimal
добавленный текст передаётся отдельным framed-блоком. Массив images
остаётся одинаковым. Текстовая задача оценивает отчёт об исходнике BSL.
В пробе чтения из пикселей исходник отсутствует, ожидаемая строка
используется только для оценки ответа. Проверяется точная транскрипция
в отдельном запросе. Этот результат не устанавливает, как модель
обработала картинку в запросе на отчёт.

Исследование использует локальную Ollama 0.16.1, зафиксированные digest,
seed 17/29, temperature 0.3, context 8192 и прежние бюджеты текста.
Qwen2.5VL получает 384 токена на генерацию. На запрос отведено 180 секунд,
на траекторию 540 секунд. Клиент выполняет запросы последовательно.
Таймаут транспорта сохраняется и останавливает допуск следующего запроса
до явного возобновления. Пределы диска и RSS проверяются перед траекторией.
Изображение ограничено 2 MiB и 4 млн пикселей. Проверки формата, размеров,
символических ссылок и декодирования относятся к этому стенду.
Синтетические изображения используют фиксированный шрифт Pillow 13.
Pillow входит в дополнительные зависимости для тестов, а генерация
входов выполняется в зарегистрированном окружении.

Пауза между траекториями задаётся файлом PAUSE в каталоге вывода.
Возобновление проверяет сохранённый префикс и окружение. Каталог
незавершённой попытки требует явной проверки. Вторую фазу можно начать
после проверки полного журнала и runtime-end первой.

Архивный аудит восстанавливает запросы и эффекты по закреплённому
исходному коду. Полное воспроизведение файлов выполняется на Linux
с Python 3.12. Для аудита используются сохранённые результаты OCR и
ответы моделей. Результаты исследования ограничены указанными каналами,
операцией и профилями. Источники, правила допуска и критерии оценки
зафиксированы до новых ответов.

## Доступность маршрутов перед первым ответом

В первой опубликованной регистрации запрос к Qwen2.5VL 3B завершился
HTTP 500 при загрузке модели. Ollama указала нехватку системной памяти.
Запрос сохранился в журнале, модель не вернула ответ, потребитель
не записал отчёт. Локальная проверка загрузки с пустым prompt,
context 8192 и batch 64 дала ту же ошибку. Для воспроизведения
мультимодального маршрута нужен хост, на котором Ollama 0.16.1
загружает закреплённую модель с параметрами исходной регистрации.

[Ревизия доступности](image_study_issue520/route-revision.json) до
получения первого ответа сохраняет исходную регистрацию и журнал
сбоя. В основной матрице 108 ранее активных сценариев прямой подачи
изображения и все 20 проб транскрипции отмечены `unavailable`.
Статусы LSB и JPEG alpha сохраняются. Текстовые профили, случаи,
инструкция и критерии прежние. У 432 активных сценариев
максимум 1296 запросов. Прямую обработку изображения этой моделью
в данной среде оценить не удалось.
