# Покрытие статических реквизитов форм (#533)

Сравнение использует те же три локальные выгрузки A/B/C и тот же
`discover_elem_forms`, что при [приёмке #502](final_acceptance_issue502.md).
База сравнения — `863b98ae62948fb36cf5cc1ef01909e4d477a817`,
Python 3.12, v8unpack 1.2.13. Полнота относится к объявленным именам
верхнего уровня в двух выбранных артефактах выгрузки.

| Выгрузка | Всего | Полные до → после | Неполные до → после | Неподдержанные до → после |
| --- | ---: | ---: | ---: | ---: |
| A | 2216 | 450 → 1933 | 11 → 11 | 1755 → 272 |
| B | 76 | 55 → 76 | 0 → 0 | 21 → 0 |
| C | 3738 | 70 → 3589 | 70 → 70 | 3598 → 79 |
| Всего | 6030 | 575 → 5598 | 81 → 81 | 5374 → 351 |

| Причина исходного отказа | До | После | Решение |
| --- | ---: | ---: | --- |
| Обычные формы `0-26` / `0-27` | 379 / 4027 | 0 | Приоритет по приросту. Позиции сверены с адаптерами FormElements26/27 |
| Управляемый корень версии `2` | 263 | 0 | Та же секция реквизитов FormElements4, сверка по raw |
| Отделённые вложенные записи при корне `3` / `4` | 354 | 0 | Проверить форму записи, вернуть только верхний уровень |
| Прочие форматы, доступная пара без поддерживаемой секции | 347 | 347 | Для этих версий нужна отдельно подтверждённая секция. Основная доля, 224 формы, относится к `0-25-16` |
| Пустой корень и неизвестная версия адаптера | 4 | 4 | Доступные JSON-файлы не подтверждают нужную секцию. Нужны исходные данные |
| Лимит чтения 2 МБ на файл | 81 | 81 | Неполные. Поддержка потребует измерить ресурсы и ограничить разбор |
| Нет файла пары | 0 | 0 | Отдельный статус `source_unavailable` |
| Прочая неизвестная причина | 0 | 0 | Остаток проверяется отдельно от известных причин |

`audit_form_coverage_issue533.py` берёт ожидаемые имена из позиций raw
без вызова анализатора для вычисления эталона, затем сверяет полный
детерминированный отчёт. Все 5598 отчётов совпали с эталоном. Для исходных
575 приватное сравнение по порядковому номеру и хэшу подтвердило те же
значения и порядок. Рабочие результаты и входные данные не нужны CI.
Синтетические тесты проверяют пустоту, сохранение Unicode, raw-указатель,
вложенный реквизит и отказ при рассогласовании.

Запустите скрипт дважды с одинаковым порядком выгрузок и `PYTHONPATH`
соответствующего checkout. Параметр `--private-receipt` принимает новый
локальный путь. Приватные квитанции по формам не предназначены для
публикации. Отчёт в stdout содержит только агрегаты.

Эпик [#211](https://github.com/MRDK80/v8unpack-agent/issues/211) касается
динамических операций BSL. Здесь общая точка только в декларативном
слое формы. Вложенная опись, выполнение BSL и текущее runtime-дерево
в контракт не входят.
