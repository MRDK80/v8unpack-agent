# Покрытие динамических конструкций форм (#218)

Анализ статический: результат описывает места операций в исходнике,
а не конечное runtime-дерево. Declared-структура хранится отдельно.
Exact-ссылка на доказанное создание не делает вычисляемое имя точным;
условие имеет известное выражение и unknown runtime truth. Ссылка действует
в сохранённом контексте ветви. Цикл даёт один source-шаблон, без разворачивания
числа фактических элементов.

## Матрица

Частоты взяты из [сплошной проверки кандидатов #212](research/dynamic_forms_issue212.md).
Это размер исследованного scope, а не достигнутый recall реализации.
Каждая строка операции присутствует в модели #213, локальном детекторе
#214, индексе #215 и opt-in контексте/проекции #217.

| Конструкция | Подтверждённых мест #212 | Detector | Linking | Data flow | Ограничение |
|---|---:|---|---|---|---|
| `element_add` | 1897 | Нативная коллекция, сигнатура | Exact creator reference, локальные копии | Расширенный отложен | Вычисляемое имя остаётся partial |
| `element_insert` | 67 | Нативная коллекция, сигнатура | Цель, parent/before при доказанной идентичности | Расширенный отложен | Добавлено после C4; позиция не угадывается |
| `element_delete` | 204 | Нативная коллекция | Идентичность и инвалидация liveness | Расширенный отложен | Неизвестная цель не становится exact |

| `attributes_change` | 185 | Нативный batch-вызов | Закрытые локальные массивы root-реквизитов | Расширенный отложен | Сложные, вложенные и неоднозначные массивы сохраняют остаток |

Закрытые свойства: видимость, доступность, заголовок, толькоПросмотр,
путьКДанным, имяКоманды, вид, родитель, текущаяСтраница, текущаяСтрока,
подсказка, ширина и высота. Они не являются универсальными свойствами
любого root-контекста формы: совпадающий реквизит или неподтверждённое
расширение контекста не получают native-property proof.

Восемь видов и закрытый whitelist соответствуют 62071 из 79770 подтверждённых
мест кандидатов (77,81%). Вне scope остаются 17699 мест. Это не population
precision/recall. Отдельные 14793 unresolved-кандидата исследования не равны
числу истинных операций и не используются как готовый потенциал data flow.
Условные места, циклы и вычисляемые имена входят в указанные виды;
отдельные частоты этих разрезов не измерялись.

## Связи и недоказанный остаток

| Класс | Результат MVP | Решение |
|---|---|---|
| Локальная копия доказанной ссылки | Exact при сохранённом proof и контексте | Реализован в #215 |
| Литеральный lookup по доказанному namespace | Exact при уникальности и liveness | Реализован в #215 |
| Вычисляемое имя результата `Add` | Exact-ссылка на creator, отдельное partial-имя | Реализован; имя не угадывается |
| Вычисляемое значение setter | Partial/expression по источнику | Перенос scalar literals отложен |
| Условие / препроцессор | Обе ветви, exact-выражение, unknown truth | Реализован; активная ветвь не выбирается |
| Цикл | Один шаблон; fresh in-body ссылка может быть exact | Инварианты внешних ссылок консервативны |
| Parent / before / command / data_path | Связь с отдельным resolution и provenance | Объединение только при доказанной идентичности |
| Конфликты / повторное удаление / циклы связей | Все операции сохраняются, диагностика отдельно | Реализован, последнее значение не объявляется истинным |
| Параметр helper / неоднозначные effects / CFG joins | Unresolved без нового доказательства | B0 #216 не прошёл quality gate; более широкие классы не измерены |
| Общие модули и другие BSL-модули | Непрозрачный эффект / unresolved | Межмодульный анализ вне MVP |
| Неполные declarations / byte/grammar/control budgets | Явный incomplete/unsupported/unavailable | Не подменяется пустой complete-описью |
| Ordinary form / выполнение конфигурации | Не восстанавливается managed runtime-модель | Вне scope |

[Эксперимент #216](research/dynamic_forms_issue216.md) не доказывает отсутствия
пользы любого data flow: отложен конкретный B0. Новый класс требует отдельно
зафиксированных proof-контракта, gold и измерений по принятым инженерным
порогам. Нельзя просто снять инвалидацию непрозрачных вызовов ради уменьшения
FN. При недостаточном релевантном gold решение остаётся открытым.

## Публичные представления и проверка

`DynamicOperationIndex` сохраняет source, процедуру, вид операции,
operation resolution, имя/значения и guards. `DynamicBindingIndex` хранит
raw и bound раздельно; кандидаты не реконструируют runtime-экземпляры.
`FormContext.summary` остаётся declared-слоем, `dynamic_analysis` — отдельным
opt-in блоком. В LLM-проекции conditional ортогонален exact/partial/unresolved;
при неполном контексте отсутствие guard не доказывает безусловность.

В `framed` все source-derived имена и значения — `kind=text`, а не доверенные
labels. Секция динамики атомарна; бюджет не отделяет операцию от статуса.
Малый prefix-бюджет может исключить секцию и последующий BSL целиком.
Канонический индекс при этом остаётся доступен через library API.
Token-only бюджет с произвольным счётчиком без символьного предела может
требовать перебора; монотонность счётчика не предполагается.

Post-run report содержит только агрегаты динамики, без BSL и новых путей.
`operations=exact+partial+unresolved`, `conditional<=operations`; raw и bound
не складываются. Кандидаты и операции считаются отдельно: batch-реквизиты
не умножают одну операцию. Формы с отказом учитываются отдельно, не теряются.
Default-off сохраняет прежние metadata, фрагменты и ключи отчёта.

Позитивные и отрицательные проверки восьми видов и 13 свойств, комментарии,
строки, shadowing, mixed fixture, цикл-шаблон, непрозрачный helper, конфликты
и согласованность report — `tests/test_dynamic_forms_acceptance.py` вместе
с тестами detector/linker/context. Бюджеты и framing проверяются отдельными
регрессионными тестами. [Синтетический пример](../examples/dynamic_forms_demo.py)
показывает declared + dynamic exact + partial + unresolved без production-данных.

[Итоговые измерения](research/dynamic_forms_issue218.md) отдельно показывают
качество на gold, доступность полного анализа, парную детерминированность
и стоимость. Количество записей корпуса не выдаётся за TP/recall.
Имена, литералы и относительные пути в library/проекции не обезличены;
публичное исследование содержит только агрегаты. Модели не запускались;
формат `framed` не объявляется гарантией устойчивости модели к injection.
