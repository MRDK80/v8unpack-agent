# Данные для восстановления обычной формы

`capture_ordinary_form(extraction_root: Path, form_dir: str)` из
`v8unpack_agent.ordinary_form_data` читает одну форму из нормализованного
дерева `v8unpack.extract`. Формат проверен с saby v8unpack 1.2.13 на CF и
EPF с обычными формами версии `0-27`. Передайте относительный POSIX-путь
каталога формы внутри дерева. У исходного каталога сохраняются исходные
файлы. Для работы требуется дерево с `Configuration.json` или
`ExternalDataProcessor.json` в корне и сырые файлы формы.

Функция возвращает JSON-совместимый словарь с `schema_version` равным
`ordinary-form/1`. Поля пакета имеют следующие источники.

| Поле | Содержимое |
| --- | --- |
| `owner_kind`, `owner_uuid` | Тип CF или EPF и UUID контейнера из корневых метаданных |
| `form_dir`, `stem` | Путь и основа имён файлов формы в дереве upstream |
| `metadata` | Полный разобранный `<stem>.json` с заголовком и блоками `form` |
| `identity` | Разобранный `<stem>.id.json` с UUID формы |
| `elements` | Полный разобранный `<stem>.elem.json`, включая упорядоченные элементы, свойства, ссылки и `raw` |
| `module` | Текст `<stem>.obj.bsl` без BOM, с сохранением переносов строк |

Происхождение каждого необработанного блока определяется файлом-источником,
ключом и исходной позицией в списке. Такие блоки сохраняются в структуре.
Исходный бинарный контейнер формы в пакет не входит.
`validate_ordinary_form_data(data)` проверяет версию схемы и обязательные
поля и поднимает `OrdinaryFormDataError` при ошибке.

Пустой модуль сохраняется, а отсутствующий файл модуля вызывает ошибку.
Включаемые области `include_` и `includr_`, пустые деревья и другие форматы
форм пока вне поддерживаемого подмножества. Для полной сборки контейнера нужен
также контекст остального дерева владельца. Старые сырые выгрузки подходят,
если содержат перечисленные файлы. При наличии только `FormArtifact` и
`form_elements_index.json` требуется новое извлечение из CF или EPF.
Результаты проверки upstream описаны в [протоколе #568](research/ordinary_form_build_issue568.md).
